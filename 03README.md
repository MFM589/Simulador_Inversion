
# Simulador de Inversión - Alimento Premium para Equinos

Simulador interactivo para calcular retornos de inversión en la producción de alimento premium hidropónico peletizado para caballos.

## Requisitos
- Python 3.11+
- Streamlit
- Pandas
- Numpy
- Plotly

## Instalación Local
```bash
pip install -r requirements.txt
```

## Ejecución Local
```bash
streamlit run app.py
```

## Despliegue en Streamlit Cloud
Este proyecto está configurado para ser desplegado directamente en Streamlit Cloud.
